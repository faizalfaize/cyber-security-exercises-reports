# Lab 06 – Cybersecurity Investigation and Security Assessment

**Student:** Faizal Saifudeen  
**Course:** Cybersecurity (CS)

## 1. Introduction

Security investigation involves collecting information, examining system behaviour, and identifying signs of potential security incidents. This practical focuses on understanding how technical information can support cybersecurity analysis.

## 2. Areas of Study

The practical introduces the following activities and concepts:

- Understanding the importance of collecting system information.
- Examining technical data to identify unusual behaviour.
- Learning how security assessment tools support investigations.
- Understanding the role of logs and system records.
- Recognising indicators that may suggest security problems.
- Considering appropriate methods for documenting findings.

## 3. Analysis

Effective cybersecurity investigation requires careful observation and accurate interpretation of information. System records and technical outputs can help explain what happened in an environment. Maintaining clear documentation also makes findings easier to review and communicate.

## 4. Learning Outcomes

This lab highlights the importance of systematic investigation, evidence-based analysis, and responsible handling of technical information. It also develops awareness of how security findings can support future prevention measures.

## 5. Conclusion

Lab 06 introduces important ideas in cybersecurity investigation and assessment. The concepts provide a useful foundation for analysing system information and documenting security observations.
