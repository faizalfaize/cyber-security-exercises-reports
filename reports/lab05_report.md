## 1. Lab Overview

System security involves protecting operating systems, applications, and stored information from unauthorised access. Understanding vulnerabilities helps security professionals identify areas that need improvement.

## 2. Main Topics

This practical report covers the following security concepts:

- Understanding common operating system security risks.
- Exploring the importance of secure system configurations.
- Learning how vulnerabilities can affect computer systems.
- Understanding the purpose of security assessment tools.
- Recognising the importance of software updates and patches.
- Considering methods for reducing security risks.

## 3. Technical Discussion

A system may become vulnerable when software is outdated, permissions are incorrectly configured, or unnecessary services remain active. Regular security assessments and appropriate updates help reduce these risks. Security findings should be reviewed carefully before applying corrective actions.
