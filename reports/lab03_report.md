# Lab 03 – Web Application Security Assessment

**Student:** Faizal Saifudeen  
**Course:** Cybersecurity (CS)

## 1. Purpose of the Practical

Web applications can contain security weaknesses that may expose data or allow unauthorised access. This practical introduces the process of examining a web application and understanding common security risks in a controlled testing environment.

## 2. Practical Areas

The main areas covered in this exercise include:

- Understanding the structure and functionality of a web application.
- Exploring how web applications handle user input and requests.
- Identifying potential weaknesses in application behaviour.
- Understanding the role of security testing tools.
- Observing how insecure application configurations can create risks.
- Considering suitable measures to improve application security.

## 3. Security Analysis

Web application security depends on proper input validation, access control, secure configuration, and safe handling of user data. Testing in an authorised environment helps demonstrate how weaknesses may be identified before they can be exploited by attackers.

## 4. Learning Outcomes

This practical introduces important concepts in web security assessment. It highlights the need to test applications systematically, understand observed results, and recommend appropriate security improvements.

## 5. Conclusion

Lab 03 provides an introduction to web application security and the importance of identifying vulnerabilities in a controlled environment. It strengthens the foundation for further practical work in cybersecurity.
