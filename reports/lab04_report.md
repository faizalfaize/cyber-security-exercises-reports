## 1. Introduction

Network security is an important part of protecting computers and information systems. Monitoring network communication helps security professionals understand how devices exchange data and recognise unusual activity.

## 2. Practical Focus

This practical introduces key network security concepts, including:

- Understanding network communication between devices.
- Examining network interfaces and connection information.
- Learning how network traffic can be monitored.
- Exploring the purpose of packet analysis tools.
- Understanding common network security risks.
- Recognising the importance of authorised network testing.

## 3. Technical Understanding

Network traffic analysis helps identify communication patterns and investigate possible security issues. Packet analysis tools can provide information about protocols, source and destination addresses, and communication behaviour. This information can support troubleshooting and security investigations.

## 4. Skills Developed

Through this topic, I gained an understanding of network monitoring concepts and the role of traffic analysis in cybersecurity. I also learned why network information must be interpreted carefully and why testing should only be performed with proper permission.

## 5. Conclusion

Lab 04 introduces the fundamentals of network security and traffic analysis. These concepts are useful for understanding network behaviour and recognising potential security problems.
