# Lab 01 – Getting Familiar with Kali Linux

**Student:** Faizal Saifudeen  
**Course:** Cybersecurity (CS)

## 1. Overview

Kali Linux is a Linux distribution designed for cybersecurity learning, security testing, and digital forensics. This practical focuses on understanding its environment, exploring its available tools, and becoming familiar with basic system and network commands.

## 2. Practical Work

The following areas and commands form part of this lab:

- Explored the Kali Linux desktop, application menu, system settings, and terminal.
- Reviewed the available cybersecurity tools and their purposes.
- Used `whoami` to identify the active user account.
- Used `hostnamectl` and `uname -a` to examine system and kernel information.
- Used `df -h` to inspect available disk space.
- Used `ip a` to view network interfaces and IP address information.
- Explored file-system navigation using commands such as `cd` and `ls`.
- Reviewed package installation and management using `apt`.
- Examined how tools such as Nmap, Wireshark, and other security utilities support cybersecurity activities.

## 3. Understanding and Observations

Kali Linux provides a specialised environment with many tools used in security assessment and investigation. Its terminal makes it possible to perform system administration and network-related tasks efficiently. Understanding the purpose of each tool is important before using it in a practical security assessment.

## 4. Skills Gained

This lab introduced me to the Kali Linux working environment and its cybersecurity-focused utilities. I developed an understanding of basic system inspection, network interface information, filesystem navigation, and software package management.

## 5. Final Remarks

Exploring Kali Linux helped me understand why it is widely used in cybersecurity education and testing. The knowledge gained in this practical provides a starting point for learning more advanced security tools in the following labs.
