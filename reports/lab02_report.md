## 1. Background

Cybersecurity practical work involves understanding how systems communicate, identifying possible weaknesses, and learning how security tools are used to examine computer environments. This lab focuses on developing familiarity with practical security concepts and command-line utilities.

## 2. Practical Activities

The lab provides an opportunity to explore common cybersecurity techniques and their purpose, including:

- Becoming familiar with the Linux terminal and security-related commands.
- Understanding how network information can be collected.
- Exploring tools used to identify hosts and available services.
- Learning the importance of checking software and system configurations.
- Understanding how security testing can help identify potential weaknesses.
- Observing command output and considering what it reveals about a system.

## 3. Technical Discussion

Cybersecurity tools help administrators and security professionals understand the condition of a system. Network discovery can reveal connected devices, while service inspection can help identify software that may require updates or stronger configuration. These activities should only be performed on systems where permission has been granted.

## 4. Learning Outcomes

This practical provides an introduction to the role of security tools in system and network assessment. It also highlights the importance of interpreting results carefully rather than relying only on automated tool output.

## 5. Conclusion

Lab 02 develops foundational knowledge of practical cybersecurity techniques. Understanding the purpose of security tools and using them responsibly are important steps towards more advanced security assessments.
