# Lab 07 – Practical Cybersecurity Tools and Techniques

**Student:** Faizal Saifudeen  
**Course:** Cybersecurity (CS)

## 1. Practical Overview

Cybersecurity requires a combination of technical knowledge, suitable tools, and responsible testing methods. This practical focuses on applying security concepts and understanding how technical tools contribute to protecting computer systems.

## 2. Work Covered

The following topics provide the focus of this practical:

- Becoming familiar with the purpose of cybersecurity utilities.
- Understanding how technical tools assist in security testing.
- Examining system and network information.
- Recognising possible security weaknesses.
- Understanding the importance of secure configurations.
- Considering ways to document findings and improve protection.

## 3. Observations and Discussion

Security tools are useful for examining systems and identifying potential problems. However, their output must be interpreted with care. A proper security assessment should be conducted only with authorisation and should include clear documentation of observations and recommendations.

## 4. Skills and Knowledge

This practical reinforces the importance of analytical thinking, responsible tool usage, and systematic security assessment. It also connects earlier Linux and cybersecurity concepts with practical security work.

## 5. Conclusion

Lab 07 provides an opportunity to strengthen foundational cybersecurity knowledge. The practical emphasises responsible testing, careful analysis, and the importance of protecting systems against potential threats.
